# คู่มือผู้ใช้ OLE88 Admin (Staging)

อัปเดต 26 กันยายน 2026

## สถานะและขอบเขตการใช้งาน

ระบบ staging ใช้งานได้สำหรับเข้าหน้า Admin, ดู Dashboard, สร้างและแก้ไขฉบับร่าง และดูตัวอย่างแคมเปญ โดยตรวจสอบแล้วว่า service ทำงาน, `/health` และ `/ready` ตอบสำเร็จ และไฟล์สลับภาษาโหลดได้

Staging เชื่อมต่อ LINE OA ทดสอบแล้ว โดย webhook สาธารณะเปิดเฉพาะ `https://olo1.duckdns.org/webhooks/line` ผ่าน HTTPS reverse proxy ส่วนแอปและหน้า Admin ยังคงฟังเฉพาะ `127.0.0.1:3000`:

- ใช้หน้า Admin จากเครื่องผู้ดูแลผ่าน SSH tunnel ตามหัวข้อ 1 เท่านั้น; `/admin` ไม่เปิดให้เข้าโดยตรงจากอินเทอร์เน็ต
- Webhook รับ event จาก OA ทดสอบได้ แต่แคมเปญที่เป็น DRAFT จะไม่ส่งข้อความต้อนรับ/โปรโมชัน และคู่มือนี้ไม่ได้สั่งเผยแพร่แคมเปญ
- ห้ามใช้กับลูกค้าจริงหรือใส่ข้อมูลส่วนบุคคลจริง การเปิดใช้ webhook ไม่ใช่การอนุมัติส่งแคมเปญ

## 1. เชื่อมต่อหน้า Admin ผ่าน SSH tunnel

เปิด PowerShell บนเครื่อง Windows แล้วรัน:

```powershell
ssh -i "$env:USERPROFILE\.ssh\ole88-staging-admin" `
  -o IdentitiesOnly=yes `
  -o ExitOnForwardFailure=yes `
  -N -L 127.0.0.1:3000:127.0.0.1:3000 `
  root@79.108.225.211
```

ใส่ passphrase ของ SSH key ใน prompt ของ SSH เท่านั้น อย่าส่ง passphrase, รหัสผ่าน Admin หรือ token ให้ผู้อื่นหรือใส่ในแชต

เมื่อเชื่อมต่อสำเร็จ หน้าต่าง PowerShell จะค้างอยู่โดยไม่มีข้อความใหม่ นี่เป็นพฤติกรรมปกติของ tunnel:

1. เปิดหน้าต่างนี้ค้างไว้ตลอดเวลาที่ใช้ Admin
2. เปิดเบราว์เซอร์ไปที่ <http://127.0.0.1:3000/admin>
3. หากหน้าจอไม่อัปเดต ให้กด `Ctrl+F5`
4. เมื่อปิดหน้าต่าง tunnel หน้า Admin จะเชื่อมต่อไม่ได้ ให้เปิด tunnel ใหม่เมื่อต้องการกลับมาใช้

หากแจ้งว่า local port 3000 ถูกใช้งานอยู่ ให้ปิด tunnel เก่าที่ค้างอยู่ก่อน หลีกเลี่ยงการเปิด tunnel ซ้ำหลายหน้าต่าง

## 2. เข้าสู่ระบบและเลือกภาษา

1. กรอก username และ password ของบัญชี Admin ที่สร้างไว้บน VPS
2. หน้าเริ่มต้นใช้ภาษาไทย กดปุ่ม `English` ด้านบนเพื่อเปลี่ยนเป็นภาษาอังกฤษ
3. ระบบจำภาษาที่เลือกไว้ในเบราว์เซอร์เครื่องนั้น การเปลี่ยนภาษามีผลเฉพาะป้ายเมนู ไม่ได้แปลหรือแก้ข้อความในแคมเปญ
4. กด `ออกจากระบบ` เมื่อต้องการจบการใช้งาน โดยเฉพาะบนเครื่องที่ใช้ร่วมกัน

ไม่มีบัญชีหรือรหัสผ่านเริ่มต้น หากเข้าสู่ระบบไม่ได้ ให้ติดต่อผู้ดูแลระบบ ห้ามสร้างบัญชีใหม่โดยแก้ฐานข้อมูลเอง

## 3. อ่าน Dashboard

Dashboard แสดงตัวเลขจาก PostgreSQL ตามช่วงวันที่และแคมเปญที่เลือก ใช้ตัวกรองและปุ่ม `ใช้ตัวกรอง` เพื่อเปลี่ยนช่วงเวลา:

- วันที่อ้างอิงเขตเวลาไทย
- สถิติผู้ติดตามนับจาก LINE follow events ที่ระบบประมวลผลแล้ว ไม่ใช่จำนวนผู้เห็นแคมเปญ
- คิวตรวจสอบหลักฐานและรายการปัญหาปฏิบัติการอาจว่างเปล่า เพราะ staging นี้ใช้ข้อมูลทดสอบเท่านั้น
- Dashboard ว่างอาจหมายถึงยังไม่มี event ที่ได้รับหรือประมวลผลในช่วงที่เลือก ไม่ได้ยืนยันว่าการตั้งค่าทุกส่วนของ LINE ทำงานครบ

ปุ่มรีเฟรชใช้โหลดข้อมูลล่าสุด ส่วนรายการปัญหามีตัวกรองสถานะและโหลดเพิ่มเมื่อมีข้อมูล

## 4. สร้างและแก้ไขฉบับร่าง

1. ในส่วน `แคมเปญ` กด `สร้างจากเทมเพลต`
2. เลือกเทมเพลตที่ต้องการ และกำหนด campaign code ที่ไม่ซ้ำ โดยใช้ตัวอักษรอังกฤษ ตัวเลข `_` หรือ `-`
3. เปิดรายการด้วยปุ่ม `เปิด`
4. แก้ชื่อ รายละเอียด ช่วงเวลา จำนวนสิทธิ์ ปุ่ม กิจกรรม และข้อความตามความต้องการ
5. ในช่อง `Hero image HTTPS URL` คือภาพโปรโมชันหลัก และช่อง `Secondary image HTTPS URL` คือภาพรายละเอียด/วิธีการ กด `Use supplied OLE88 artwork` เพื่อเติมภาพสองรูปที่เตรียมไว้ รูปจะแสดงในตัวอย่างภาพและ LINE Flex preview
6. ปุ่ม `เพิ่มปุ่ม` และ `เพิ่มกิจกรรม` ใช้เพิ่มรายการในส่วนที่เกี่ยวข้อง
7. กด `บันทึกฉบับร่าง` เพื่อบันทึก ระบบจะแจ้งข้อผิดพลาดหากข้อมูลไม่ผ่าน validation
8. กด `ดูตัวอย่าง` เพื่อตรวจข้อความและการ์ด รวมถึงรายการ field ที่ต้องแก้
9. กลับไปเปิดแคมเปญภายหลังเพื่อแก้ไขฉบับร่างได้

ถ้าต้องการเริ่มจากแคมเปญเดิม ให้เปิดรายการแล้วใช้ `ทำสำเนา` และกำหนด code ใหม่ การแก้ไขแคมเปญที่กำลัง Active ถูกจำกัดตามกติกาของระบบ สำหรับงานเพิ่มภาพนี้ให้บันทึกเป็น DRAFT และอย่ากด `เผยแพร่`

### ข้อจำกัดสำคัญใน Staging

- รูป OLE88 ที่เตรียมไว้ให้โหลดจาก HTTPS บนโดเมน staging; ปุ่มเติมภาพเพียงใส่ URL ในฟอร์ม ไม่ได้บันทึกหรือเผยแพร่ให้อัตโนมัติ
- กด `บันทึกฉบับร่าง` เพื่อเก็บ URL และตรวจด้วย `ดูตัวอย่าง`; อย่ากด `เผยแพร่` ในงานนี้
- URL รูปภาพอื่นที่กรอกต้องเป็น HTTPS และเปิดให้ LINE ดึงรูปได้; ห้ามใช้ URL ภายใน/private
- อย่าใส่รหัสผ่าน, token, LINE user ID, ข้อมูลลูกค้า หรือข้อมูลจริงในข้อความหรือหลักฐานทดสอบ

## 5. เกี่ยวกับ DuckDNS และการเข้าผ่านโดเมน

ชื่อ `olo1.duckdns.org` ชี้มายัง VPS และมี HTTPS สำหรับ webhook กับภาพแคมเปญที่กำหนดไว้เท่านั้น หน้า Admin ยังปิดจากอินเทอร์เน็ตและเข้าได้ผ่าน SSH tunnel ตามหัวข้อ 1

การเตรียมชื่อ DNS ทำได้ที่ <https://www.duckdns.org/>:

อย่าเปลี่ยน DNS, reverse proxy หรือ firewall เองโดยไม่ตรวจแผน deploy ก่อน เก็บ DuckDNS token ไว้เป็นความลับ ห้ามใส่ใน Git, คู่มือนี้, browser URL หรือแชต

**อย่าเปิดพอร์ต 3000 สู่สาธารณะ และอย่าเปิด `/admin` บน reverse proxy** การเปลี่ยนแปลงของภาพต้อง deploy release และเพิ่ม exact paths ที่ allowlist ใน Nginx เท่านั้น ห้ามตั้ง static directory serving หรือ proxy ทั้ง `/campaign-images/` โดยไม่จำกัดชื่อไฟล์

ให้ใช้ SSH tunnel ตามหัวข้อ 1 เพื่อเข้า Admin ต่อไป

## 6. ออกจากระบบและแจ้งปัญหา

กด `ออกจากระบบ` หลังใช้งาน หากหน้าเว็บแจ้ง session หมดอายุ ให้เข้าสู่ระบบใหม่ หาก service หรือฐานข้อมูลไม่พร้อม โปรดส่งข้อความแจ้งผู้ดูแลพร้อมภาพหน้าจอที่ไม่มีรหัสผ่าน, token, ข้อมูลส่วนบุคคล หรือรายละเอียดลับ

## สำหรับผู้ดูแลระบบ

รายละเอียดเทคนิคและข้อจำกัดของ Campaign Manager อยู่ใน [คู่มือ Campaign Manager](./admin-campaign-manager.md). การตั้งค่าและทดสอบ LINE จริงต้องทำตาม [แผน staging แบบ controlled test](./staging-test-plan.md) แยกต่างหาก และยังไม่ครอบคลุมในคู่มือผู้ใช้นี้
